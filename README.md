# 🏫 ABC High School — School Management Website

A simple and responsive **School Management Website** developed using **HTML, CSS, and JavaScript**. This project demonstrates the fundamental concepts of front-end web development, including multi-page navigation, forms, CSS styling, JavaScript DOM manipulation, event handling, validation, and dynamic content.

## 📌 Project Overview

**ABC High School Website** is a static educational website designed to provide visitors with essential information about a school and its activities.

The website includes dedicated pages for:

* 🏠 Home
* 📖 About Us
* 📝 Student Admission
* 👨‍🏫 Teachers
* 📞 Contact Us

The project was created as a practical demonstration of HTML, CSS, and JavaScript concepts in a real-world website structure.
